# lifactory 無料動作確認サンプル

Mac版LibreOffice Impress用の、結婚式プロフィールブックの表紙1ページです。
購入前に、文字と写真を変更して保存・PDF出力できるか、ご自身のMacで試せます。

[無料サンプルをダウンロード（ZIP）](https://raw.githubusercontent.com/LuckOfWise/lifactory-samples/main/downloads/impress-cover-sample-v1.zip)

メール登録・支払いは不要です。ZIPには1ページのODP、使い方、2つのフォントとSIL OFLライセンスを収録しています。アプリ本体は含みません。

確認環境はMac版LibreOffice 26.2.4.2（英語UI）です。Windows/Linux、スマートフォン/iPad、他のアプリは未検証・対象外です。印刷・製本も未検証です。

文字枠を選びF2で編集し、写真枠を右クリックしてReplace…（置換）を試してください。保存して開き直し、PDFも確認してください。詳しい手順はZIP内のSTART_HERE.txtにあります。

[8ページ・写真7枠の800円版をminneで見る](https://minne.com/items/46597236)

購入・決済はminneの作品ページ内で行います。このリポジトリには有料版の全ページは含まれません。

サンプルODPはご自身の環境の動作確認用です。再配布・転売はできません。フォントにはZIP内の各SIL Open Font Licenseが適用されます。
